# StarterPlay — NestJS Microservices

A simple microservice project using **NestJS**, **Redis**, and **Prisma**.  
Includes a **Gateway** for HTTP requests and an **Auth Service** for authentication.

---

## 🚀 Features
- NestJS microservice architecture  
- Redis transport for inter-service communication  
- Prisma ORM with PostgreSQL  
- JWT authentication  
- Centralized error handling with `RpcExceptionFilter`
